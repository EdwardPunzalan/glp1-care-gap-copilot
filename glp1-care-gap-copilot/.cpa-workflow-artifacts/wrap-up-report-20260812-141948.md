## Not verified in production

Two paths are configuration-gated. Both have unit coverage and both degrade to a
fallback that *was* verified live, which is how they currently run:

- **LLM narrative** — requires `ANTHROPIC_API_KEY`; no real API call has ever
  been made, so model latency and instance egress rules are unmeasured
- **Lab-order button** — requires `LAB_PARTNER_NAME` resolving to an active
  `LabPartner` offering the configured tests

This is a deliberate scope decision, recorded in the README under
*Verification status*.
